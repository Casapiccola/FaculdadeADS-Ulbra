# Faculdade ADS — ULBRA

Repositório de **atividades e exercícios acadêmicos** do curso de **Análise e Desenvolvimento de Sistemas**. O objetivo é registrar a evolução do aprendizado em programação e desenvolvimento de software.

## Organização do repositório

| Pasta | Conteúdo |
| :--- | :--- |
| [`1 Semestre - Frontend`](./1%20Semestre%20-%20Frontend) | Práticas introdutórias de desenvolvimento frontend. |
| [`2 semestre - Backend`](./2%20semestre%20-%20Backend) | Exercícios e atividades de fundamentos de backend. |
| [`2 semestre - POO`](./2%20semestre%20-%20POO) | Atividades de programação orientada a objetos. |

## Sobre os códigos

Os exemplos refletem o conteúdo e o estágio de aprendizado de cada disciplina no momento em que foram desenvolvidos. Não representam, necessariamente, padrões de arquitetura ou de segurança prontos para produção.

**Formação em andamento:** atualmente no 3º semestre de ADS.
